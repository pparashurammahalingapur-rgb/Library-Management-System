# Library Book Inventory Management System

## Description

This project is a command-line Java application that manages a library's book inventory.

Features:

- Add Book
- View All Books
- Update Book
- Delete Book

Data is stored in memory using Java ArrayList.

---

## Requirements

- Java JDK 8 or above

---

## Compile

javac *.java

---

## Run

java Main

---

## Menu

1. Add Book
2. View Books
3. Update Book
4. Delete Book
5. Exit
